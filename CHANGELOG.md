## 0.4.0 release notes

The first release on PyPI, and the first under the name `polydisc`
(formerly `pysson-disc`, never published). Versions 0.2.0 and 0.3.0
existed only as version numbers during development and were never
released (the `v0.3.0` tag only gives python-semantic-release its
starting point); their changes are listed here.

### New

- **Periodic box axes.** `Box(bounds, periodic=(True, True, False))`
  (one flag per axis, or a single bool) wraps candidates that leave one
  face back in through the opposite one, wraps the neighbour grid, and
  measures every distance with the minimum image, so copies of the box
  tile space without overlaps. Hard axes keep their walls. A periodic
  edge must be at least `2 * (2 * rmax + gap)` long. On the command line:
  `--periodic xy`.
- **Minimum surface gap.** `sample(..., gap=g)` guarantees
  `|c_i - c_j| >= r_i + r_j + g` for every pair, across periodic faces
  too, as a constraint while sampling (the packing still saturates),
  unlike `spacing`, which dilates afterwards. On the command line:
  `--gap`. Recorded on `Packing.gap` and in saved metadata.
- `nearest_neighbour_gaps`, `gap_report` and `report` take the region
  and measure periodic boxes with the minimum image.
- Boxes and balls in 2D and 3D as containers (`Box`, `Ball`); a flat
  carpet is a thin `Box`.
- Radius distributions: discrete, lognormal, normal and uniform
  (`RadiusSpec`), truncated by `truncate` or explicit `rmin`/`rmax`.
- Diagnostics of what was realised: radius bias against the request,
  the container's boundary bias (`geometric_bias`), nearest-neighbour
  gaps, fill and projected-area fractions (`report`).
- The `polydisc` command (`generate`, `report`, `radii`) with TOML, YAML
  or JSON configs and named profiles.
- A Streamlit dashboard (`pip install "polydisc[dashboard]"`,
  `dashboard/app.py`), deployable to Streamlit Community Cloud.

### Changed

- Renamed from `pysson-disc`; the sampler was rewritten: cells of
  `2 * rmax` with linked-list contents keep the neighbour scan 3x3(x3)
  whatever the size ratio, 2.4-4.3x faster than before with up to 4x
  less memory.
- Thin slabs fill: out-of-container candidates are redrawn instead of
  retiring the active point, and in 3D boxes the depth is drawn exactly
  (Archimedes' hat-box theorem).
- With `gap=0` and no periodic axis, seeded results are bit-identical
  to those before periodic axes and gaps were added.

### Packaging

- Python 3.13 and 3.14. NumPy is no longer capped below 2.4 (Numba caps
  it itself); Numba 0.63 or newer. Tested with Numba 0.68 and NumPy 2.5.
- MIT licence file included in the distributions.
